# TFR Construction Management Platform

## Overview
The TFR Construction Management Platform is an internal tool for TFR Construction, managing the entire project lifecycle from bid tracking to project completion. Built with TypeScript, React, and PostgreSQL, its core purpose is to centralize project data, user management, and daily operations to boost efficiency and oversight. The platform aims to enhance compliance, integrate AI for operational intelligence, streamline crew and subcontractor management, and ensure high data quality.

## System Architecture
The platform features a modern web stack designed for robustness and comprehensive functionality:

-   **Frontend**: React with TypeScript, utilizing Wouter for routing, TanStack Query for data management, and styled with Tailwind CSS and shadcn/ui for a responsive user experience.
-   **Backend**: Express.js in TypeScript, secured with CORS, rate limiting, and JWT token versioning.
-   **Database**: PostgreSQL on Neon, managed with Drizzle ORM. The schema supports audit logs, billing, time clock, AI operations, crew/skills, equipment, data quality, and subcontractor management.
-   **Authentication**: JWT-based authentication using httpOnly cookies, bcrypt for password hashing, and token versioning, featuring RBAC across six user roles and self-service registration.
-   **Security**: Multi-layered protection including rate limiting, comprehensive audit logging, and file validation.
-   **UI/UX**: Clean, functional interface built with shadcn/ui components and Tailwind CSS.
-   **Key Features**:
    -   **Authentication & Authorization**: Secure JWT with RBAC.
    -   **User Management**: Admin tools for accounts, roles, and activation.
    -   **Time-Clock System**: Native time-clock with GPS, shift management, and approvals.
    -   **Audit & Compliance**: Comprehensive audit logging.
    -   **Billing Events**: Financial tracking for various billing events.
    -   **Project Lifecycle Management**: CRUD for Bids, Projects, Estimates, Procurement, and Change Orders, including a strict Change-Order State Machine.
    -   **Daily Operations**: Project notes, media uploads, and daily progress.
    -   **Time & Materials**: Time entry with approval workflows.
    -   **Calendar & Time-Off**: Event and time-off request management.
    -   **Dashboard**: Real-time KPIs and navigation.
    -   **File Storage & Permissions**: Management via Replit Object Storage with presigned URLs and granular ACLs.
    -   **AI Senior PM + CFO System**: AI-driven task generation, profitability analysis, scheduling, ordering, bid tracking, and billing automation using OpenAI GPT-4, including role-specific tasks and CFO-level financial analysis.
    -   **Takeoff + Estimating Engine**: Comprehensive system for managing project plans, interactive drawing tools (linear, area, volume, count, note), measurement persistence, and quantity summaries. Includes document viewing, import of PDF plans with PDF.js rendering on canvas using Vite-compatible worker configuration, secure PDF serving via presigned URLs from object storage to prevent CORS/403 errors, and integration with project details.

Frontend loads PDFs using authenticated requests with credentials. This approach eliminates CORS issues and maintains security through server-side authorization.

-   **Document Display Improvements**: Fixed document list to display filename as fallback when title field is empty, ensuring all uploaded documents show meaningful names to users.
-   **Import to Takeoff Button**: Updated button visibility logic to use server-validated MIME type (`application/pdf`) instead of document type classification, preventing errors from attempting to import non-PDF files and supporting PDFs regardless of their type classification (PLANS or OTHER).
-   **Fullscreen Takeoff Mode**: Added fullscreen toggle to TakeoffWorkspace component using Fullscreen API with proper state management, ESC key handling via fullscreenchange event listener, and dynamic Maximize/Minimize icon in header for enhanced user experience during takeoff operations.
-   **Document Deletion**: Implemented secure document deletion feature with `DELETE /api/documents/:id` endpoint restricted to ADMIN and MANAGER roles (matching the system's global RBAC design). Deletion process: (1) validates document and project existence, (2) verifies Admin/Manager authorization, (3) removes file from object storage, (4) explicitly deletes related project_plans (which cascades to takeoff_sheets), (5) deletes document record, (6) logs audit trail. Frontend includes delete button with confirmation dialog in document list, proper loading states, and cache invalidation after deletion to maintain UI consistency.
-   **Multi-Page PDF Support**: Implemented automatic detection and import of multi-page PDF documents in takeoff workspace. When importing a PDF via "Import to Takeoff", the system now: (1) downloads and processes the PDF using pdfjs-dist on the server to count pages, (2) creates one takeoff sheet per page with naming format "Document Name - Page N", (3) sets sheetIndex (0-based) for each sheet, (4) uses database transaction for all-or-nothing creation with batch insert for efficiency. Frontend updated to render the correct page from multi-page PDFs based on sheetIndex. Validation ensures PDF is valid before creating any database records, with clear error messages for corrupted or missing files.
-   **Preset Scale Calibration**: Added common scale presets for architectural, civil, and structural drawings to streamline calibration workflow. Users can now select from 24 predefined scales organized into three categories: Architectural (9 scales from 1/16"=1'-0" to 3"=1'-0"), Civil/Site (7 scales from 1"=10' to 1"=100'), and Structural (8 scales). Each scale displays its label and description (e.g., "1/4" = 1'-0" - Common floor plans"). Scale calculations based on 96 DPI standard where pixels-per-foot is computed as 96 / scale ratio. Preset scale panel appears when a sheet is selected but not yet calibrated, complementing the existing manual calibration option. Users can choose either method: click two points for manual calibration or select a preset architectural/civil/structural scale for instant setup.
