# Message coworkers, clients, and subs

Unified inbox for direct messages, project channels, and external chat with subs/clients.

## How to do it

1. Open /messages.
1. *New conversation* lets you pick anyone in your org or any external contact (sub, client, vendor).
1. Project channels are auto-created per project — anyone assigned to the project is a member.
1. Drag a file into the message box to share it. Files attached here also appear under the project's *Documents* tab.

## Tips

- Mention someone with `@` to send them a notification even if they've muted the channel.
- External recipients get an email with the message and a reply link — they don't need a login.
