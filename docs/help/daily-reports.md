# File a daily report

Capture crew, weather, photos, and notes for every project, every day.

## How to do it

1. Open the project → *Daily Reports → New report* (or use the mobile app, which works offline).
1. Date is set to today; weather auto-fills from the project address.
1. Add crews — each crew row records hours, headcount, and the cost code worked.
1. Add notes (delays, deliveries, visitors). The Markdown editor accepts inline images.
1. Attach photos. The mobile app uploads in the background once it's back online.
1. Click *Submit*. The report is emailed to subscribers (configured under *Project → Settings → Email distribution*).

## Tips

- Use the *Voice note* field on mobile — the transcript becomes the report body, ready to edit.
- Schedule the daily report email to send automatically each evening under *Project → Settings → Daily report schedule*.
