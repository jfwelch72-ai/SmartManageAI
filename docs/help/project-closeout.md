# Close out a project with the Closeout Package

Collect all handover deliverables — warranties, lien waivers, as-builts, permits, and inspection records — on a single checklist, then export a verified package for the owner in one click.

## Setting up a closeout checklist

1. Open the project and click the **Closeout** tab.
1. A default template pre-populates the checklist with standard categories: O&M Manual, Warranty, As-Built, Lien Release, Final COI, Punch List, Inspection, and Permit.
1. Assign each item to a team member and set a due date.

## Using Auto-Pull

Click **Auto-Pull** to scan the project and automatically attach existing records — warranty documents, lien waivers, permits, inspection reports, punch list items, and plan documents — to the matching checklist items. Items with sources attached move to **Ready** automatically.

## Completing items manually

For items that cannot be auto-pulled, upload documents directly to the checklist item. Accepted formats include PDF, DOCX, and images.

## Walkthrough mode

Open **Punch List → Walkthrough** to see open punch items grouped by location — useful for moving through a site efficiently during a final walk.

## Exporting the package

1. Click **Export Package**. The system builds a ZIP, verifies its integrity, and uploads it to secure storage.
1. When status shows **READY**, click **Download** to retrieve the package via a signed URL.
1. If the build fails, status shows **FAILED** with an error message; no partial archive is stored.

## Tips

- You can re-export at any time — each export creates a new, independently verified package.
