# Track DBE goals and certifications

Monitor DBE participation against project goals; export the certified report for the agency.

## How to do it

1. Open /dbe-goals.
1. Each project shows the goal % and the actual DBE participation calculated from subcontracts and POs.
1. Drill into a project to see the per-vendor breakdown: certifying agency, certification expiration, and dollars committed/paid.
1. *Export agency report* generates the form your funding agency requires (FHWA, state DOT, etc.).

## Tips

- Certifications nearing expiration appear in the compliance dashboard so you can renew before the project closeout report.
