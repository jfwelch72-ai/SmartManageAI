# Run a quick PDF takeoff

Set scale, measure, and tag each measurement against a cost code.

## How to do it

1. Open a bid → *Takeoff* tab → upload a PDF plan set (single file, up to 32 GB).
1. Once the sheet thumbnails appear, click the sheet you want to measure.
1. Click the *Calibrate* tool, then click two points on a known dimension (e.g. a 20'-0" line). Type `20` ft. Scale is now locked for this sheet.
1. Pick a tool — *Linear*, *Area*, *Count*, or *Volume* — and start measuring. Each measurement appears in the right-hand panel with quantity and unit.
1. Right-click any measurement to assign a cost code or assembly. Quantities flow into the estimate the moment you tag them.

## Tips

- Hold `Shift` while drawing to constrain a line to 0° / 45° / 90°.
- Each sheet remembers its own scale — re-calibrating one sheet does not affect another.
- Use *Copy to similar sheets* on the right-click menu to broadcast a measurement across all sheets that share a layout (e.g. typical floor plates).

## Troubleshooting

- **Tiles look blurry on a large PDF** — the renderer is still streaming high-res tiles. Wait 10–15 seconds; quality improves as more of the file downloads.
