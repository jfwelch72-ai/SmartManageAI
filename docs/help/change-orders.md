# Create and approve change orders

Track scope changes from request through approval and into billing.

## How to do it

1. Open the project → *Change Orders → New*.
1. Pick *Type* (Owner CO, Subcontract CO, or Internal).
1. Add line items. Each line is a cost code + quantity + unit cost; the contract value updates automatically.
1. Attach supporting documents (RFI thread, sub quote, sketch).
1. Send for approval. The CO appears in the owner's queue (*Approvals* tab) — they sign electronically.
1. Once approved, the CO posts to the SOV and the GMP/contract value updates everywhere (forecast, AIA billing, profitability).

## Tips

- Internal COs don't go to the owner — use them to record scope shifts that don't change contract value.
- If the owner uses email-only signoff, switch *Approval mode* to *Email* — they get a one-click approval link with no login.
