# Navigate the Project workspace

Each project is a single page with side-tabs for every workflow. Here's where each one lives.

## How to do it

1. *Overview* — KPIs, recent activity, and the Live Profitability tile.
1. *Schedule* — CPM Gantt with critical path, baseline compare, and PDF export.
1. *Daily Reports* — file from the field or web; supports photos, weather auto-fill, and crew time.
1. *RFIs / Submittals* — full pipeline with external assignees and overdue alerts.
1. *Procurement* — POs, vendor invoices, and 3-way match.
1. *Financial* — Schedule of Values, AIA billings, change orders, retention, lien waivers.
1. *Documents* — versioned plan sets, contracts, and BIM/IFC files.

## Tips

- The tab order is configurable per-organization — Admins can reorder it under *Company Settings → Project tabs*.
- Press `g` then a tab letter (e.g. `gs` for Schedule) when focused on the project workspace for keyboard navigation.
