# Request and approve leave

PTO, sick, jury, bereavement — request, balance, and accrual all in one place.

## How to do it

1. Open /leave-management.
1. *Request leave* — pick type, dates (full or partial day), and reason.
1. Manager gets the request in their /approvals queue. Approval pushes the leave onto the project calendar and pre-blocks the time-clock.
1. Balances and accruals are visible to the user in real time.
