# Run SWPPP inspections

Weekly and post-rain SWPPP inspections with photo evidence and corrective actions.

## How to do it

1. Open /swppp-inspections → *New inspection*.
1. Inspection type defaults based on weather (post-rain if NWS reports >0.25" rain in last 24h).
1. Walk the BMPs. For each control, mark *Pass* or *Issue* and (if an issue) attach photos and a corrective action with assignee + due date.
1. Submit. The inspection is logged with timestamps; corrective actions appear in the responsible person's task queue.

## Tips

- Overdue inspections trigger reminders to the project manager and (configurably) the safety officer.
