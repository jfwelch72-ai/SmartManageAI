# Track tasks across projects

A personal task list and a per-project task list share the same engine.

## How to do it

1. Open /my-work for your personal queue or /tasks for the cross-project view.
1. *New task* — set assignee, due date, priority, and (optional) related project / RFI / submittal.
1. Status pipeline is configurable per-org under *Company Settings → Task pipelines* (defaults: Open → In Progress → Blocked → Done).

## Tips

- Tasks created from a daily report or RFI keep a back-link so you can jump to context with one click.
