# Build a CPM schedule

Build dependencies, set baselines, and export a print-quality Gantt PDF.

## How to do it

1. Open the project → *Schedule*.
1. Add tasks. Each task has duration, predecessors (FS, SS, FF, SF), and an optional resource.
1. Run *Calculate critical path*. The critical chain is highlighted in red.
1. Set a baseline (*Baseline → Save current as baseline*). Future views show a baseline-vs-actual delta band.
1. *Export PDF* renders a print-quality Gantt sized to your paper choice.

## Tips

- Imports support MS Project XML and Primavera XER files.
- Drag a task on the Gantt to reschedule; predecessors update automatically.
