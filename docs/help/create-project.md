# Create your first project

Spin up a project with the right template, address, and team in under two minutes.

## How to do it

1. Open /projects and click *New project*.
1. Pick a template (Commercial / Residential / Civil) — this seeds the cost-code list, default schedule milestones, and document folder structure.
1. Fill in *Project name*, *Site address*, *Owner / GC contact*, and *Contract amount* if known. The address is what powers the weather widget and the GPS geofence for time-clock.
1. Assign a Project Manager and (optionally) a default Superintendent. Both will receive RFI / submittal / daily-report notifications.
1. Click *Create*. You'll land on the new project's *Overview* tab with all the side-tabs (Bids, Schedule, Daily Reports, etc.) ready.

## Tips

- You can change the template-seeded cost codes from *Project → Financial → Cost Codes* later — nothing is locked in.

## Troubleshooting

- **No templates show up** — your org's admin disabled them. Ask them to re-enable templates under *Company Settings → Project templates*.
