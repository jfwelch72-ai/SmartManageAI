# Plan with the project calendar

Combined calendar across all your projects with filters and iCal export.

## How to do it

1. Open /calendar.
1. Filter by project, event type (milestones, deliveries, inspections, time-off), and assignee.
1. Click + to add an event. Events created here also appear on the related project schedule.
1. Subscribe via iCal — *Settings → Personal → iCal feed* — to mirror the calendar into Google / Outlook.
