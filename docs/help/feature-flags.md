# Toggle features per organization

Super Admins enable/disable modules per tenant via feature flags.

## How to do it

1. Open /admin → *Feature flags*.
1. Search for the flag (e.g. `AI_PROVIDER_TAKEOFF`, `BIM_VIEWER`).
1. Toggle per-organization or set a default. Changes are audit-logged.
1. Use *Presets* to apply a bundle of flags (e.g. *Enterprise plan*) in one click.

## Tips

- Customers don't see the flag UI — only Super Admins do. Customer-visible toggles live in Company Settings.
