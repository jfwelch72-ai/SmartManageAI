# Move deals through the CRM pipeline

A 7-stage pipeline for converting leads into signed contracts.

## How to do it

1. Open /crm → *Deals*.
1. Drag a deal across the pipeline stages: Lead → Qualified → Estimating → Proposal Sent → Negotiation → Won → Lost.
1. Each card shows owner, value, expected close date, and the next activity. Click for the full detail (notes, calls, emails, meetings).
1. When a deal hits *Won*, click *Convert to project* to spin up a project with the deal's contacts, value, and notes pre-filled.

## Tips

- Stage transitions can trigger notifications, document generation, or task creation via the Workflow Builder.
