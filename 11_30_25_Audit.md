## 🔵 SYSTEM ARCHITECTURE SUMMARY

### High-Level Overview
The TFR Construction Management Platform is an enterprise-grade, white-label SaaS solution for construction project lifecycle management. It employs a modern full-stack architecture with multi-tenant data isolation, comprehensive role-based access control (RBAC), and AI-powered optimization across all platform features.

### Technology Stack

| Layer | Technology | Purpose |
|-------|------------|---------|
| **Frontend** | React 18 + TypeScript | UI framework with type safety |
| **Routing** | Wouter | Lightweight client-side routing |
| **State Management** | TanStack Query v5 | Server state, caching, mutations |
| **UI Components** | shadcn/ui + Radix UI | Accessible component library |
| **Styling** | Tailwind CSS | Utility-first CSS framework |
| **Backend** | Express.js + TypeScript | REST API server |
| **Database** | PostgreSQL (Neon) | Primary data store |
| **ORM** | Drizzle ORM | Type-safe database operations |
| **Authentication** | JWT + httpOnly cookies | Secure session management |
| **AI Integration** | OpenAI GPT-4 | AI-powered analysis features |
| **File Storage** | Replit Object Storage (GCS) | Document and media storage |
| **PDF Processing** | pdfjs-dist, pdfkit | PDF rendering and generation |
| **Interactive Canvas** | react-konva, Konva | Takeoff drawing tools |

### Architectural Patterns

1. **Multi-Tenant Architecture**
   - Organizations (tenants) isolated via `organizationId` foreign keys
   - `gcOrganizationId` on projects for contractor association
   - SUPER_ADMIN bypasses tenant filtering for platform oversight

2. **Security Layers**
   - JWT token versioning for instant session revocation
   - bcrypt password hashing (cost factor 10)
   - Rate limiting: Auth (5/15min), Sensitive (10/15min), API (100/15min)
   - Input sanitization for all user inputs
   - Comprehensive audit logging

3. **Role-Based Access Control (9 Roles)**
   - SUPER_ADMIN: Platform administrator (cross-tenant visibility)
   - ADMIN: Organization administrator (full org access)
   - MANAGER: Project and team management
   - SUPERINTENDENT: Field operations oversight
   - ESTIMATOR: Bid and estimate management
   - OFFICE_MANAGER: Administrative functions
   - MAINTENANCE_MANAGER: Equipment and maintenance
   - HOURLY_EMPLOYEE: Limited field access
   - VENDOR: External vendor portal access

4. **Trade-Specific Features (22 Trades)**
   - General Contractor, Concrete, Earthwork, Asphalt Paving
   - Roofing, Electrical, Plumbing, HVAC, Carpentry
   - Masonry, Drywall, Painting, Flooring, Landscaping
   - Demolition, Steel Erection, Glazing, Insulation
   - Fire Protection, Low Voltage, Solar, Waterproofing
   - OTHER (custom trade with AI-powered onboarding)

## 🔵 BACKEND MECHANICS

### Server Entry Point (`server/index.ts`)
- Express app initialization
- Middleware stack: CORS, JSON parsing, cookies, rate limiting
- Route registration via `registerRoutes()`
- Vite dev server integration
- AI scheduler initialization (disabled in dev mode)

### Authentication Pipeline (`server/auth.ts`)
```
Request → Cookie Extraction → JWT Verification → Token Version Check → User Attachment → Next
```
- **hashPassword()**: bcrypt with cost factor 10
- **generateToken()**: JWT with 7-day expiration
- **revokeUserTokens()**: Increments tokenVersion for instant revocation
- **Sanitized User**: Excludes `passwordHash`, `tokenVersion` from responses

### Multi-Tenant Security (`server/orgFilter.ts`)
```typescript
getOrgIdForFilter(req) → { shouldFilter, orgId, isSuperAdmin, mustDenyAccess }
```
- SUPER_ADMIN: No filter (sees all)
- Regular users: Filter by organizationId
- No org users: `mustDenyAccess = true` → empty results

### Rate Limiting (`server/rateLimiter.ts`)
| Limiter | Window | Max Requests |
|---------|--------|--------------|
| authLimiter | 15 min | 5 |
| sensitiveLimiter | 15 min | 10 |
| apiLimiter | 15 min | 100 |

### Audit Logging (`server/auditLogger.ts`)
- All CREATE, UPDATE, DELETE operations logged
- Change tracking with before/after values
- Entity type and ID recorded
- User and organization context captured

### Input Validation & Sanitization
- **Zod schemas** for request validation
- **sanitizeShortText()**: HTML escaping, length limits
