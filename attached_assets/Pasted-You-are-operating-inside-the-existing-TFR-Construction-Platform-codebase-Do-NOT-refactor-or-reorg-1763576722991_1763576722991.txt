3) SUBCONTRACTOR REMAINING BALANCE API + PROFITABILITY UPDATE
=============================================================================

A) UPDATE /api/subcontractor-payables TO RETURN REMAINING BALANCE  
---------------------------------------------------------------------
File: server/routes.ts  

Replace the SELECT for subcontractor payables with:

   SELECT 
      s.id AS subcontractor_id,
      sc.id AS contract_id,
      sc.project_id,
      sc.contract_amount,
      COALESCE(SUM(sp.amount), 0) AS total_paid,
      sc.contract_amount - COALESCE(SUM(sp.amount), 0) AS remaining_balance,
      p.name AS project_name,
      s.company_name
   FROM subcontractorContracts sc
   JOIN subcontractors s ON sc.subcontractor_id = s.id
   JOIN projects p ON p.id = sc.project_id
   LEFT JOIN subcontractorPayments sp ON sp.contract_id = sc.id
   GROUP BY sc.id, s.id, p.id;

Return this full object in JSON.
