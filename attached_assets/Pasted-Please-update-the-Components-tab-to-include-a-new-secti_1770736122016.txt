Please update the Components tab to include a new section called “Body Components.”
All Body Components must support global style controls using Tailwind CSS utilities, including:
•	Font family, size, weight, color, and line height
•	Padding and margin
•	Background options: image upload, solid color, or gradient
•	Responsive support (desktop / mobile)

General Requirements
•	All Body Components must be:
o	Draggable and reorderable
o	Fully editable after insertion
o	Responsive
o	Compatible with global undo/redo
•	Styling must rely on Tailwind CSS utility classes only
•	Components must integrate seamlessly with:
o	Layout tab
o	Global Components
o	AI “Suggest Components” feature
Please implement and validate end-to-end behavior for all Body Components.
