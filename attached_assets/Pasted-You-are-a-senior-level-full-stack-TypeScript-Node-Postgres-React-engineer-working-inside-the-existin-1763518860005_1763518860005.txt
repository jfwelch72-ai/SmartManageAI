SECTION 7 – HYBRID SUBCONTRACTOR COST + BILLING + PROFITABILITY INTEGRATION
────────────────────────────────────────

Implement a hybrid subcontractor tracking system that starts simple but can expand later. It must track:

- Subcontractor quotes at bid stage
- Subcontractor contracts and cost to TFR at award
- TFR-supplied materials/labor credits
- Subcontractor invoices and partial payments
- Remaining balances
- Subcontractor impact on project profitability
- Subcontractor payables (what TFR owes subs)
- AI PM/CFO tasks and alerts related to subs

Use a hybrid approach: relatively simple relational structure now, but flexible enough to extend toward full AIA-style pay apps.

1. Schema – Subcontractor core tables:
   - If not already present, create a subcontractors master table:
     - subcontractors:
       - id, name, contactName, phone, email, address, notes, active, createdAt, updatedAt

   - Subcontractor contracts per project:
     - subcontractor_contracts:
       - id
       - projectId fk
       - subcontractorId fk
       - scopeDescription text
       - originalQuoteAmount decimal(12,2) – their quoted price
       - approvedContractAmount decimal(12,2) – agreed amount after negotiation
       - tfrSuppliedMaterialsCredit decimal(12,2) – total value of materials TFR provides that reduce their bill
       - tfrSuppliedLaborCredit decimal(12,2) – if TFR self-performs a portion originally in sub scope
       - netContractAmount decimal(12,2) – computed as approvedContractAmount - tfrSuppliedMaterialsCredit - tfrSuppliedLaborCredit
       - status: enum("PENDING", "ACTIVE", "COMPLETE", "CLOSED", "CANCELLED")
       - quoteReceivedDate date
       - contractApprovedDate date
       - notes text
       - createdAt, updatedAt

   - Subcontractor payments (partial or full):
     - subcontractor_payments:
       - id
       - subcontractorContractId fk
       - paymentNumber integer
       - invoiceReference text – sub’s invoice number or reference
       - scheduledAmount decimal(12,2) nullable – optional planned amount
       - paidAmount decimal(12,2)
       - paidDate date
       - method text (e.g., CHECK, ACH, WIRE)
       - notes text
       - createdAt, updatedAt

   - Optionally, a simple pay schedule rather than full AIA SOV:
     - subcontractor_billing_schedule:
       - id
       - subcontractorContractId fk
       - label or drawNumber text
       - plannedAmount decimal(12,2)
       - scheduledBillDate date
       - status enum("PLANNED","READY_TO_BILL","BILLED","PAID")

   - The system should compute:
     - totalPaid = SUM(paidAmount)
     - remainingBalance = netContractAmount - totalPaid

2. Bidboard integration:
   - On the bid/bid-detail pages, add UI to:
     - Record subcontractor quotes per trade/scope.
     - Link each quote to a subcontractor record and project/bid.
     - Mark one quote as “selected” at time of award.
   - When a bid is converted to a project:
     - Optionally prompt: “Create subcontractor contracts from selected quotes?”
     - If confirmed, create subcontractor_contracts records from the chosen quotes, with:
       - originalQuoteAmount = quoted amount
       - approvedContractAmount = same value initially

3. Awarded project integration:
   - In the project management view:
     - Add a “Subcontractors” tab showing:
       - All subcontractor_contracts for that project
       - Quotes, approved contract amounts, TFR-supplied credits, net contract amount
       - A list of payments made and outstanding balances
     - Add forms to:
       - Adjust tfrSuppliedMaterialsCredit and tfrSuppliedLaborCredit as TFR decides to supply materials or self-perform portions.
       - Add subcontractor payments, referencing their invoices.

4. Profitability integration:
   - Update the profitability engine to:
     - Include subcontractor netContractAmount and payments in project cost computations.
     - Track:
       - subContractOriginalTotal = SUM(approvedContractAmount) per project
       - subContractAdjustedTotal = SUM(netContractAmount) per project
       - subPaidToDate = SUM(paidAmount) for all subcontractor_payments per project
       - subRemainingLiability = subContractAdjustedTotal - subPaidToDate
   - Ensure profitabilityInsights include:
     - subcontractorCostToDate
     - subcontractorRemainingLiability
     - any major deviation between originalQuoteAmount and netContractAmount (greater than some threshold).

5. Payables / “What We Owe Subs” dashboard:
   - Create a CFO/Office Manager-facing “Subcontractor Payables” screen showing:
     - A list of active subcontractor contracts across all projects, with:
       - project code/name
       - subcontractor name
       - approvedContractAmount
       - netContractAmount
       - totalPaid
       - remainingBalance
       - next scheduled billing or due date if subcontractor_billing_schedule is used
     - Filters by project, subcontractor, and status.
   - This dashboard must allow Office Manager to quickly see:
     - Who is owed money
     - How much is left to pay
     - If any payments appear overdue

6. AI PM/CFO & Daily Ops integration:
   - Extend the AI snapshot builder to include:
     - subcontractor_contracts and payments per project
     - subContractAdjustedTotal, subPaidToDate, subRemainingLiability
   - Update AI profitabilityInsights and alerts such that:
     - Projects with heavy subcontractor cost share are flagged if:
       - Sub bills are lagging behind project billing (cash flow risk)
       - Subcontractor costs far exceed original quotes (overrun risk)
     - AI tasks are generated for:
       - Office Manager: “Pay subcontractor X invoice Y for project Z by [date].”
       - Project Manager: “Review subcontractor X’s change order/request; potential cost overrun.”
   - Integrate subcontractor status into:
     - AI roleTasks for OFFICE_MANAGER, MANAGER, and ADMIN
     - AI data-quality scoring (projects missing subcontractor data where subs are used should be scored lower on financial completeness)

7. TFR-supplied materials and deductions:
   - In the subcontractor_contracts UI:
     - Add inputs for TFR-supplied materials and labor credits.
     - When updated, recalculate netContractAmount for that subcontractor.
   - In profitability:
     - Materials that TFR supplies for sub work must still count as TFR cost.
     - AI and CFO views should reflect:
       - “Subcontractor direct cost”
       - “TFR-supplied materials/labor for subs”
       - Total combined subcontract-related costs.

8. AIA-style readiness (Hybrid aspect):
   - Keep the schema and UI flexible to allow future per-sub SOV:
     - For example, subcontractor_billing_schedule can be extended to support line items later.
   - Structure code to make it easy to:
     - Add per-line-item percentages and retainage in a later iteration.
