CORE PROJECT WORKFLOWS (Post-Award)
Think of your project phase as 6 connected engines:
Project Setup → Planning → Procurement → Execution → Financial Control → Closeout
________________________________________
1. ⚙️ Project Setup (Foundation Phase)
This happens immediately after award.
Key workflows:
•	Convert Bid → Project 
•	Lock original estimate (baseline) 
•	Create: 
o	Project takeoff (v2) 
o	Budget 
o	Cost codes 
•	Upload latest plans (IFC set) 
•	Define: 
o	Locations (floors, zones) 
o	Project team 
o	Permissions 
👉 Output:
A fully structured project ready for execution
________________________________________
2. 📐 Planning & Engineering
Now you refine what you thought vs reality.
Workflows:
•	Review updated plans 
•	Revise takeoff (v2, v3…) 
•	Value engineering adjustments 
•	Create: 
o	Schedule (timeline) 
o	Schedule of Values (SOV) 
•	Submittals & material approvals 
•	RFIs (questions to designer) 
👉 Output:
Final execution plan
________________________________________
3. 📦 Procurement (Buyout Phase)
This is where money gets real 💸
Workflows:
•	Send packages to subcontractors 
•	Receive & compare quotes 
•	Award subcontracts 
•	Generate purchase orders (POs) 
•	Material procurement tracking 
👉 Connected to:
•	Takeoff quantities 
•	Budget 
👉 Output:
All trades + materials secured
________________________________________
4. 🏗️ Construction Execution (Daily Operations)
This is the “heartbeat” of the project.
Workflows:
•	Daily logs (site activity) 
•	Progress tracking: 
o	By location 
o	By takeoff item 
•	Labor tracking 
•	Equipment tracking 
•	Site photos & reports 
•	Issue tracking 
👉 Advanced (your advantage):
•	Compare: 
o	Planned vs Installed quantities 
👉 Output:
Real-time project visibility
________________________________________
5. 💰 Financial Control (MOST IMPORTANT)
This is where projects succeed or fail.
Workflows:
•	Budget tracking 
•	Cost tracking (actual vs budget) 
•	Subcontractor billing 
•	Progress billing (based on SOV) 
•	Expense tracking 
🔄 Change Orders:
•	Detect scope changes 
•	Create change order 
•	Link to: 
o	Takeoff delta 
o	Cost impact 
👉 Output:
You always know if you’re making or losing money
________________________________________
6. 🔄 Change & Risk Management
This runs parallel to everything.
Workflows:
•	Plan revisions 
•	Takeoff version comparison 
•	RFIs 
•	Issues → delays → cost impact 
•	Variation orders 
👉 Output:
Controlled chaos (instead of surprises)
________________________________________
7. 📊 Reporting & Analytics
For owners + managers.
Workflows:
•	Project dashboard: 
o	Progress % 
o	Cost status 
o	Delays 
•	Forecasting: 
o	Final cost projection 
•	Performance tracking 
________________________________________
8. ✅ Project Closeout
Final stage (often neglected but critical)
Workflows:
•	Punch list (remaining work) 
•	Final inspections 
•	As-built drawings 
•	Document turnover 
•	Final billing & retention release 
👉 Output:
Project officially completed
________________________________________
🧠 The Real Power (your system advantage)
Most tools treat these as separate modules.
👉 You should CONNECT everything:
Example:
•	Takeoff → feeds → Budget 
•	Budget → feeds → SOV 
•	SOV → feeds → Billing 
•	Takeoff changes → auto → Change Orders
⚡ If you want to beat competitors
Focus on these 3 connections:
1.	Takeoff ↔ Budget ↔ Actual Cost 
2.	Plan Revisions → Auto Change Orders 
3.	Field Progress → Real-time Cost Impact
🧩 Simple Summary
After award, your system should answer:
•	What are we building? → Plans & Takeoff 
•	How much should it cost? → Budget 
•	How much is it costing? → Actuals 
•	Are we on track? → Schedule + Progress 
•	What changed? → Change Orders
