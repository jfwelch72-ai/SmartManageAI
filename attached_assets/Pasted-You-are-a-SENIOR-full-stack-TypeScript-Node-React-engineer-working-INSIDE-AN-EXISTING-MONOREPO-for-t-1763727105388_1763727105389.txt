PART 2 – MEASUREMENT DATA MODEL & CALIBRATION
==================================================

Create a table `takeoff_measurements`:

- id (PK)
- sheet_id (FK → takeoff_sheets)
- type: "LINEAR" | "AREA" | "VOLUME" | "COUNT" | "NOTE"
- label: string (user editable, e.g. “Slab A”, “Sidewalk – East”)
- points: JSON array of `{ x: number, y: number }` in canvas coordinates
- arc_data: JSON for arc shapes (optional – center, radius, angles) if needed
- depth_feet: number | null (for volume)
- count: number | null (for count groups; can also be derived from points)
- note: string | null
- color: string | null
- visible: boolean (default true)
- source: "USER" | "AI"
- status: "DRAFT" | "CONFIRMED"
- computed_length_ft: number | null
- computed_area_ft2: number | null
- computed_volume_cy: number | null
- metadata: JSON (tags, scope type, categories, etc.)
- created_at
- updated_at

-------------------------------
Calibration Tool
-------------------------------
Per sheet, store:

- `scale_px_per_foot`
- `units` ("ft", "m")

User flow:
1. Click “Set Scale”.
2. Prompt to click first point (A).
3. Prompt to click second point (B).
4. Prompt for real-world distance (“24’” or “24'-0"”).
5. Compute:
   - `pixelDistance = distance(A, B)`
   - `realDistanceFt` from user input.
   - `scale_px_per_foot = pixelDistance / realDistanceFt`.
6. Save to `takeoff_sheets`.

Use this scale to compute:
- Length (ft)
- Area (ft²)
- Volume (CY = area_ft2 × depth_ft / 27).

Also:
- Allow AI to pre-populate scale if a printed scale (e.g. “1” = 20’”) is detected on the sheet.
